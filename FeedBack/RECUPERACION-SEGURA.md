# Recuperación segura de acceso

Por seguridad, este proyecto no guarda contraseñas en archivos, capturas ni repositorios.

Para recuperar el acceso:

1. Abre la pantalla de acceso de Entrenador o Cliente.
2. Escribe el correo de la cuenta.
3. Pulsa **Recuperar contraseña**.
4. Abre el enlace recibido por correo.
5. Define una clave nueva de al menos 8 caracteres.

Las claves temporales deben cambiarse inmediatamente después del primer acceso.
